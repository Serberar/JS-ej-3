# Ejercicios de JavaScript · 3. El DOM

Ejercicios para aprender a **leer y modificar una página web desde JavaScript**. Cada ejercicio tiene su enunciado (`.md`), su página (`.html`) y la solución (`.js`).

## Contenido

| Carpeta | Tema |
|---|---|
| `1.dom-selectors` | Seleccionar elementos con `querySelector` / `querySelectorAll`, por clase, etiqueta o atributo (`data-function`). |
| `2.dom-modify` | Crear, insertar, cambiar y eliminar elementos. |
| `3.events` | Escuchar eventos (`click`, `focus`, `input`) y reaccionar a ellos. |
| `extra` | Retos que combinan todo, como pintar listas y añadir a cada elemento un botón que lo elimina. |

## Cómo verlos

Abre el `.html` de cada ejercicio en el navegador con la consola de desarrollador abierta.
